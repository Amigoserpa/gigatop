# Environment requirements

- A clean clone of `https://github.com/Amigoserpa/gigatop.git` with `origin/release/gigatop-v3` fetched.
- Linux, Node.js 22.13 or newer, npm and Git.
- GitHub repository access sufficient to fetch the release branch.
- GitHub Pages deployment permission is needed only after explicit owner approval.
- The repository Pages environment and `gigatop.io` custom-domain configuration must remain available.
- Headless Chromium or Chrome is required for production visual and accessibility checks.
- No runtime secret, database, storage bucket, analytics key or third-party API is required by this release.

Run every command from the repository root. The static build output is `dist/client/`.
