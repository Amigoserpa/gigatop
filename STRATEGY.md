# Gigatop V3 — Strategisches Konzept

## Markt-Analyse: Schweizer Private AI

### Schmerzpunkte Schweizer Unternehmen
1. **DSG/nDSG Compliance** — Schweizer Datenschutzgesetz verlangt lokale Datenverarbeitung
2. **US CLOUD Act** — US-Cloudanbieter können Daten an US-Behörden herausgeben
3. **Keine Token-Kosten** — OpenAI/Anthropic kosten pro Request = unkontrollierbar
4. **Data Leakage** — Prompts gehen in Training der grossen KI-Modelle
5. **Vendor Lock-in** — Abhängigkeit von ausländischen Plattformen
6. **Keine Customisierung** — Standard-Modelle kennen Firmenspezifika nicht

### Kaufentscheider
- **CTO/CIO**: Tech-Stack, Integration, Support
- **CISO**: Sicherheit, Compliance, Audit
- **CEO/Managing Director**: ROI, Wettbewerbsvorteil
- **Procurement**: Kosten, Verträge, SLA

### Wettbewerbsvorteil von Gigatop
- **Swiss Made**: Alles läuft lokal, keine Cloud
- **Enterprise Ready**: SAP, AD, SharePoint Integration
- **Predictable Pricing**: Einmalinvestition, keine laufenden Kosten
- **Schulung**: Swiss-German Support, Vor-Ort-Onboarding
- **Future Proof**: Ständig aktualisierte Modelle, keine Obsoleszenz

## Design Read

- Audience: C-Suite, IT Security, Procurement in Swiss mid-large companies
- Vibe: Premium Trust — serious but not boring, confident but not arrogant
- Design system: Tailwind v4 + Geist font + custom easing
- Aesthetic: Dark premium (Apple + Swiss bank — trust meets technology)
- Palette: Navy (#0E1C25) + Sand (#F6F1E8) + Terracotta (#D66B45) + Olive (#78866B)
- Dials: VARIANCE 7, MOTION 5, DENSITY 4
- Language: German (primary), English (secondary — i18n ready)
- Hero: Left-aligned text, right asset (split asymmetric), max 2 lines headline
- CTA: "Gespraech vereinbaren" (singular, no variants)
- No fake testimonials, no fake numbers
